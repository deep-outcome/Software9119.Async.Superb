# Software9119.Async.Superb

Async programming types for easier and better coding.

While packages are shipped with symbols, release build can optimize some variables away. To mitigate this inconvenience
you can use debugging package [Software9119.Async.Superb.Debug](https://www.nuget.org/packages/Software9119.Async.Superb.Debug/)
instead of release build pckg [Software9119.Async.Superb](https://www.nuget.org/packages/Software9119.Async.Superb/).

See [Software9119.Async.Superb](https://github.com/deep-outcome/Software9119.Async.Superb) repository for more.
